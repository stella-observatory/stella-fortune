星々と月の占い — Stella公式サイト 仕上げ版

改善内容
1. タロット22枚の絵柄を正しい順番（0 愚者〜XXI 世界）で確認し、旧番号入りの部分を含まない絵柄へ差し替え。番号とカード名は独立した文字として表示。
2. 三択・タロット・今日の運勢・今週の一枚・おみくじの結果表示を「星明かりの便り」に統一。カード→名前→メッセージ→言葉を持ち帰る。
3. トップからの説明重複を取り除き、占い4つの入口が早く見えるよう整理。
4. 中性的な銀髪・青い瞳の「星詠み」を案内役として扱い、各占いの画像説明も統一。タロット・おみくじの導入画像は単体の星詠みイラスト。
5. スマホでは案内画像を小さな横長の紹介欄にし、結果画像の大きさ・余白を調整。画像サイズ軽量化、遅延読み込み、コピー機能の代替処理にも対応。
